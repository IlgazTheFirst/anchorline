# Anchorline brand

**Plan around what can't move.**

The mark is an anchor whose arms are a dotted route between two stops. The coral point at the bottom is the commitment that can't move: a fixed event, a minimum stay or a home-by deadline. The planner arranges everything else around it.

| File | Use |
|---|---|
| `logo.svg`, `logo-512.png` | App icon, favicon, avatars |
| `logo-transparent-dark.svg` / `-light.svg` | Mark without the tile, for dark or light backgrounds |
| `wordmark-dark.svg` / `wordmark-light.svg` | Mark + name, for dark or light backgrounds. The text is outlined, so no font is needed. |
| `banner-dark.png` / `banner-light.png` | README header, 1600×500 |

## Rules

- Keep the coral point coral: it means "fixed".
- Don't put the mark on busy photos. Use the tile version instead.
- The itinerary in the banners is fictional sample data.
